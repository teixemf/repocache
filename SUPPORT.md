# Support

REPOCACHE is community-maintained and in active development. There is no paid support contract or guaranteed response time.

Use GitHub Issues for sanitized defect reports and enhancement requests. Include the exact version/commit, Debian 13 or AlmaLinux 10 environment, expected and actual behavior, and reproducible steps. Do not share passwords, tokens, internal infrastructure identifiers, certificates, private keys or unredacted network logs.

See [CONTRIBUTING.md](CONTRIBUTING.md) for contribution guidelines and [SECURITY.md](SECURITY.md) for private vulnerability reporting.
